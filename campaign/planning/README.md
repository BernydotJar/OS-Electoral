# Planeación estratégica de Antigua 4.0

Esta carpeta traduce la evidencia, el plan de gobierno y la organización de CampaignOS en un sistema operativo de campaña.

## Principio rector

La campaña no declara segmentos, mensajes o tácticas como aprobados sin evidencia y decisión humana. Mujeres y deporte se trabajan inicialmente como **hipótesis estratégicas transversales**: espacios para escuchar, organizar, producir política pública y construir comunidad; no como etiquetas demográficas ni mecanismos de microdirección política.

## Documentos

1. `strategic-plan-2026-2027.md`: arquitectura general de campaña.
2. `women-sport-strategic-hypothesis.md`: hipótesis, investigación y pilotos sobre mujeres y deporte.
3. `first-90-days.md`: plan operativo de doce semanas.
4. `decision-scorecard.md`: criterios objetivos para abrir o mantener cerradas tácticas.
5. `../../operations/war-room/weekly-cadence.md`: rutina de dirección y seguimiento.
6. `../../agent/deerflow/campaign-planning-harness.md`: diseño de agentes para investigación, evaluación y producción gobernada.

## Regla de uso

Cada iniciativa debe tener:

- problema verificable;
- población o territorio afectado;
- evidencia y nivel de confianza;
- responsable humano;
- entregable;
- fecha;
- indicador;
- riesgo;
- decisión o gate asociado.

Ningún documento de esta carpeta autoriza publicación, pauta, contacto ciudadano, movilización o gasto.
