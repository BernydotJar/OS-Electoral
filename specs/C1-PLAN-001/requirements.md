# C1-PLAN-001 — Sistema de planeación municipal basado en evidencia

## Objetivo

Convertir la base documental de Antigua 4.0 en un sistema interno de planeación, escucha y seguimiento centrado en problemas municipales, mujeres y deporte, sin convertir identidades o participación en perfiles de persuasión ni abrir efectos externos.

## Modo

SHIP documental y operativo interno.

## Criterios de aceptación

- [ ] Existe una arquitectura estratégica, plan de 90 días, scorecard y cadencia semanal conectados.
- [ ] Mujeres y deporte permanecen como hipótesis de política pública y escucha, no como segmento electoral aprobado.
- [ ] Las perspectivas comunitarias se registran de forma agregada, consentida y no atribuible.
- [ ] No se crean directorios de personas, historiales de comportamiento, puntuaciones políticas ni inferencias de apoyo.
- [ ] Las actividades reportadas por el usuario se registran como `PENDING_VERIFICATION` con evidencia requerida.
- [ ] La escucha en cafés comunitarios tiene un protocolo no persuasivo y de minimización de datos.
- [ ] Los archivos locales inaccesibles quedan documentados como bloqueo externo y no se afirman inspeccionados.
- [ ] DeerFlow se describe solo como posible ejecutor interno; Graph Harness y CampaignOS conservan estado, gates, autoridad y evidencia.
- [ ] Publicación, pauta, contacto, gasto, movilización y producción permanecen bloqueados.
- [ ] El repositorio y los documentos pasan validación, whitespace y safety scans.

## No objetivos

- Seleccionar votantes o audiencias individuales.
- Inferir intención de voto, preferencia, persuadibilidad o participación futura.
- Crear mensajes dirigidos, publicidad, contacto o movilización.
- Presentar actividades no verificadas como logros.
- Integrar automáticamente archivos del disco local.
- Reemplazar Graph Harness SDLC con DeerFlow.
